About Employee Management System

Simple & Powerful Employee Management System

Employee Management System is a modern web application built using Flask and SQLite. It helps organizations add, manage, update, search, and organize their employee records efficiently.

Features

  • User Registration & Login
  • Create, Update & Delete Employees
  • Search & View Employee Directory
  • Secure Password Hashing
  • Responsive Bootstrap UI

Technologies Used

Python Flask SQLite HTML CSS Bootstrap 5
